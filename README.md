# Star Wars Characters (React + SWAPI)

A simple and interactive web app to explore Star Wars characters using the SWAPI API.  
Built with **React, JavaScript, Tailwind CSS**, and a clean component architecture.

---

## 🚀 Features Implemented

### ⭐ Core Features
- **Character Listing** (Paginated)
- **Character Details Modal**
- **Search by Character Name**
- **Responsive Card Grid**
- **UI components in `/components`**

---

## 📦 Tech Stack

- **React (JS)**
- **Tailwind CSS**
- **SWAPI (Star Wars API)**
- **Lucide Icons**
- **Custom React Hooks**
